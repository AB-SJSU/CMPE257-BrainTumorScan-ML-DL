# CMPE 257 - Final Project - BrainTumorScan

This project focuses on detecting and classifying brain tumors from MRI scans using both Machine Learning (ML) and Deep Learning (DL) techniques. We will then evaluate each approach in terms of accuracy, interpretability, and computational efficiency to identify the most suitable method for medical diagnosis.

   ```bash

   ```

